# Radial Glia Downsampling Data (Recapitulation Rate)

Data for the downsampling experiment that measures how the DD (differential
dispersion) recapitulation rate scales with allotetraploid cell count,
using Radial glia -- the largest allotetraploid cell type (47,437 physical
hybrid cells in the full, non-downsampled production data).

Generated by the code in `../downsample_recapitulation_rate_code/`
(`downsample_memento_dd.py` + `merge_mash_recap.R`), orchestrated by
`../submit_downsample_jobs.sh`. Consumed by the "Recapitulation rate vs.
cell number" section of
`analysis/dd_de_analysis/dd_de_interspecies_analysis.Rmd`.

## What recapitulation rate means

A diploid DD gene (LFSR < 0.05 in the human/chimp diploid cell line
comparison) is "recapitulated" if it is *also* DD-significant (LFSR < 0.05)
in the allotetraploid hybrid comparison, with the same effect-size sign.
This experiment asks: how much does that recapitulation rate depend on how
many allotetraploid cells were available, independent of any other
cell-type-specific biology (isolated by downsampling one cell type rather
than comparing across different cell types).

## Design

- Radial glia was downsampled to 10 cell-count grid points: 100, 1,000,
  2,000, 5,000, 8,000, 10,000, 16,000, 24,000, 32,000, 40,000 physical
  hybrid cells (out of 47,437 available). The full, non-downsampled point
  is the existing production result and is not regenerated here.
- **10 independent random-subsample replicates** per cell-count point
  (raised from an initial 3; see `submit_downsample_jobs.sh`'s
  `REP_START`/`N_REPLICATES` env vars), each with its own seed
  (`seed = replicate * 1000 + n_cells`).
- At each (cell count, replicate): the production memento DD test
  (`binary_test_1d`, same filters/params as
  `de_dd_snakemake_mt_rb_mean_filtered/scripts/memento_tetraploid_dd_ct.py`)
  is rerun on the downsampled Radial glia cells only; MASH is refit across
  all 21 allotetraploid cell types with the downsampled Radial glia column
  substituted in; recapitulation rate is recomputed against the
  (unchanged) production diploid DD results.
- Downsampling keeps whole *physical* hybrid cells (both the human-allele
  and chimp-allele row per cell), not rows independently -- required by
  memento's paired-species test design.

## Files

- **`recap_Radial_glia_n<N>_rep<R>.csv`** (100 files: 10 cell counts x 10
  replicates) -- one row per run: `celltype`, `n_cells`, `replicate`,
  `n_dd_diploid` (fixed diploid DD gene count used as the denominator),
  `n_recap` (how many recapitulated at this downsampled size), `pct_recap`.
  This is the small summary file actually used by
  `dd_de_interspecies_analysis.Rmd`.
- **`tetraploid_memento_dd_results_Radial_glia_n<N>_rep<R>.csv`** (100
  files) -- the full per-gene memento DD test output (logFC, SE, p-value,
  etc. for both DE and DV/dispersion) for that specific downsampled run,
  before MASH refitting and recapitulation-rate summarization. Kept for
  anyone wanting to inspect per-gene behavior at a given downsample depth,
  rather than just the summary recapitulation rate.
- **`TEST_recap_Radial_glia_n500.csv`** /
  **`TEST_tetraploid_memento_dd_results_Radial_glia_n500.csv`** -- outputs
  from an initial small-scale test run (500 cells) used to validate the
  pipeline before the full grid was submitted; not part of the actual
  cell-count grid used in the final analysis/figure.
