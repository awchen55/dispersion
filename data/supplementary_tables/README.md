# Supplementary Tables — Dispersion Paper

Per-gene mean/dispersion/variance-decomposition estimates from
[`memento`](https://github.com/yelabucsf/scrna-parameter-estimation)'s
hypergeometric method-of-moments estimator, for the two datasets used in the
dispersion paper. Both tables share the same six metric columns and
formulas; they differ in which dataset they cover and which row-identifier
columns apply.

Generated by the `save_supplementary_tables` chunk in
`analysis/empicial_diagnostics_dispersion/dispersion_diagnostics.Rmd`
(Supplementary Table S1's `log.mean.component.of.variance` /
`log.total.variability` columns are added by a separate script,
`recompute_cHDC_total_variability.py` — see the S1-specific note below).

## How memento estimates mean and variance

Memento models observed UMI counts as a hypergeometric sample of a cell's
true transcript pool (Kim et al. 2024, PMC11556465, Eq. 8):

$$\hat{\mu}_g = \frac{1}{n_{cells}} \sum_c \frac{Y_{cg}}{N_c \, q}$$

$$\hat{\sigma}_g^2 = \frac{1}{n_{cells}} \sum_c \frac{Y_{cg}^2 - Y_{cg}(1 - q)}{N_c^2 \, q^2} - \hat{\mu}_g^2$$

where $Y_{cg}$ is the observed UMI count for gene $g$ in cell $c$, $N_c$ is
cell $c$'s total UMI count, and $q$ is the assumed capture efficiency (the
same value for every cell in a given memento run). The $Y_{cg}(1-q)$ term
corrects for the extra sampling variance introduced purely by imperfect
capture, so genes/cells aren't spuriously more "variable" just because
capture was lower.

Memento then fits a mean-variance trend across all genes in a sample,
$\log(V) \sim \text{poly}(\log(\hat{\mu}_g), \text{degree}=2)$, to separate
each gene's raw variance $V = \hat{\sigma}_g^2$ into a mean-driven baseline
$E$ (what variance a "typical" gene at that expression level would have) and
a residual ratio $r = \log(V) - \log(E) = \log(V/E)$ ("dispersion" — how far
above or below the trend line this gene's variance actually sits).

## Shared columns (both tables)

| Column | Definition |
|---|---|
| `gene` | Gene identifier — resolved gene symbol where available, Ensembl ID as fallback for genes with no resolved symbol (same convention as Cell Ranger's `features.tsv`). Kept as plain text, not a factor. |
| `celltype` | Cell type the estimate was computed within. |
| `log.mean` | $\log(\hat{\mu}_g)$ — memento's log(mean) estimate for this gene, in this group. |
| `log.dispersion` | $r = \log(V) - \log(E)$ — memento's mean-corrected dispersion (residual variance ratio, on the log scale). `log.dispersion = 0` means the gene sits exactly on the mean-variance trend for its expression level. This is a **ratio relative to the fitted trend**, not a variance component in the same units as the gene's raw variance — it runs roughly -2 to +4, not the large-negative range of the two columns below. |
| `log.mean.component.of.variance` | $\log(E)$ — the mean-variance trend's fitted value at this gene's mean expression; equivalently $E = V / \exp(r)$. "What variance this gene would have if it behaved exactly like a typical gene at this expression level" — the baseline that `log.dispersion` measures a deviation from. |
| `log.total.variability` | $\log(V)$ — memento's raw second moment (`Var[X]` of its capture-corrected relative-expression estimate), pulled directly from `adata.uns['memento']['1d_moments']` before memento's own public API discards it. Satisfies the exact identity `log.total.variability = log.mean.component.of.variance + log.dispersion` (verified to ~1e-15). |
| `percent.variability.that.is.dispersion` | A point-wise fraction in [0, 1] (not `×100`) for how much of this gene's variance is "dispersion" rather than the mean-variance trend: `1 - exp(-\|log.dispersion\|)`. Symmetric in the sign of `log.dispersion`: `r > 0` (overdispersion) simplifies to `(V-E)/V` (the excess fraction above trend); `r < 0` (underdispersion) simplifies to `(E-V)/E` (the fraction of expected variance not reached); `r = 0` gives exactly 0. |
| `percent.variability.that.is.mean` | The direct complement, `exp(-\|log.dispersion\|) = 1 - percent.variability.that.is.dispersion`. A gene exactly on-trend reads 1 here (100% of its variance is what the mean alone predicts). The two `percent.variability.*` columns always sum to exactly 1 by construction. |

## Supplementary Table S1 — Cardiac HDC pilot

Row-identifier columns: `gene`, `celltype`, `donor` (no `ploidy`/`species`
columns — this is a single human-only, non-hybrid dataset, so that
distinction doesn't apply).

- **Donors (3):** NA18522, NA19093, NA19099
- **Cell types (6):** Activated_fibroblasts, Cardiac_fibroblasts,
  Cardiomyocytes, Epithelial_cells, Foregut_endodermal_cells,
  Mesenchymal_cells

`log.mean` and `log.dispersion` come directly from the pilot's own
`mean_wide`/`res_var_wide` matrices (memento's standard
`get_1d_moments()` output — already on the same log scale as the
interspecies data below, confirmed by range). `log.mean.component.of.variance`
and `log.total.variability` are **not** present in those matrices (only the
already-mean-corrected residual is) and were recomputed separately in
`recompute_cHDC_total_variability.py`, rerunning memento on the pilot's
canonical h5ad
(`100k_permuted_annots_seurat_for_adata_conv_raw_counts_only.h5ad`, the
`new.predicted.id` cell-type annotation, grouped by
`[vireo.individual, new.predicted.id]`, `min_perc_group=0.95`, capture
efficiency `q=0.25`) and pulling the raw second moment out of memento's
internal state before it's discarded. `q=0.25` was empirically confirmed,
not assumed — cross-checked against this pilot's already-published
mean/dispersion values, with an exact match.

## Supplementary Table S2 — Interspecies (human/chimp + allotetraploid)

Row-identifier columns: `gene`, `celltype`, `ploidy`, `species`, `donor`.
Direct copy of `all_celltypes_variance_genes.csv` (too many rows —
2,333,590 — for a single Excel sheet; split or filter by `ploidy` if you
need it in `.xlsx` form).

- **`ploidy`:** `diploid` or `tetraploid`
- **`species`:** `chimp` or `human`
- **`donor`:** 7 distinct donors for each of diploid-chimp and
  diploid-human. For `tetraploid`, `donor` is a single placeholder value
  per species (`chimp`/`human`) rather than a real individual identity —
  the allotetraploid line is a single hybrid line, not multiple donors, and
  each physical allotetraploid cell contributes to *both* a
  `tetraploid`/`chimp` row and a `tetraploid`/`human` row (its chimp-allele
  view and human-allele view), not two different cells.
- **Cell types (21).**

All six metric columns are computed per `gene x celltype x ploidy x species
x donor` (diploid) or `x species` (tetraploid, no donor level) by
`memento_variance_decomposition.py`, using the same formulas documented
above.

## Notes / caveats

- `percent.variability.*` are point-wise, per-gene-per-group metrics
  describing memento's dispersion *estimator* itself (how mean-corrected it
  is, how much of a gene's variance is "extra" beyond the trend) — they are
  computed on the raw `exp(log.dispersion)` values, not on the
  quantile-normalized dispersion matrix that the paper's actual
  differential-dispersion significance test (`dd.lfsr`/`dd.logFC`,
  `diploid_dd_limma_ct.R`) uses after its own per-cell-type
  `limma::normalizeQuantiles()` step. Don't use these percentages to explain
  a specific `dd.lfsr` call without re-deriving them on the
  quantile-normalized values first.
- `log.total.variability` and `log.mean.component.of.variance` are on the
  same log scale as `log.mean`/`log.dispersion` but run in a very different
  numeric range (roughly -21 to -11, vs. roughly -2 to +4 for
  `log.dispersion`) — this is a real feature of the underlying variances
  being tiny on memento's relative-abundance scale, not a units mismatch.
